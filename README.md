# Wanderlust

A full-stack listings web app where users can browse, create, edit and delete property listings and leave reviews.

## Features
- Sign up and log in (Passport.js)
- Add, edit and delete listings (only the owner can)
- Reviews on each listing (only the author can delete)
- Image upload with Cloudinary
- Map on each listing page with Mapbox

## Tech Stack
Node.js, Express, MongoDB, Mongoose, EJS, Bootstrap, Passport.js, Cloudinary, Mapbox

## How to Run
1. Clone the repo
2. Run `npm install`
3. Add a `.env` file with your Cloudinary and Mapbox keys
4. Run `node app.js`
